Ｈ-1　やっていいのか ―― 規約の面
------------------------------------------------------------------------
【確定】Meta（Threads）側
　・外のサービスへ誘うこと自体を禁じる決まりは、見つからなかった
　・禁止されているのは、
　　「反応しないと中身を見せない（いいね・コメントしたら見られる）」
　　「反応と引き換えにプレゼントやお金」
　　「リンク先と説明が違う」「同じ内容を高い頻度で繰り返す」
　　出典: Meta コミュニティ規定「スパム」
　・反応をねだる投稿（「コメントして」「いいねして」）は削除ではなく「表示を下げる」対象
　　（コメントねだり＝"comment baiting"。言葉・数字・絵文字をコメントするよう頼むもの）
　　出典: Meta 透明性センター「エンゲージメントベイト」
　→ 「コメントしてくれた人に無料で占います」は、
　　 コメントを頼んでいる＝コメントねだりに当たる可能性が高い。
　　 さらに「コメントと引き換えに無料鑑定」は「反応と引き換えの特典」に近い。
　　 ※実際にどこまで下げられるかは公開されていない。日本では普通に行われている（Ｈ-4）

【確定】LINE 側（LINE公式アカウントガイドライン terms2.line.me/official_account_guideline_jp）
　・占いは「使えない業種」に入っていない
　・ただし「霊感商法等の悪質商法」は使えない業種。定義は
　　「不安・不幸・射幸心につけ込んで商品等を販売するもの」
　・ガイドラインは認証済み・未認証どちらのアカウントにも適用
　・友だち追加の促し方（外のSNSからの誘い方、特典で誘うこと）を禁じる決まりは見つからなかった
　・個人の情報発信は「認証済みアカウント」の対象外（未認証のままなら関係なし）

Ｈ-2　やっていいのか ―― 世間の目の面（★盲点だったこと）
------------------------------------------------------------------------
【データ】国民生活センターには、占いサイトの相談が毎年1,000件前後
【データ】大阪府の相談例：SNSで「無料鑑定」→ サイト登録 → 無料が終わるとポイント購入を求められ、
　やめようとすると「今やめると不幸になる」→ 気づくと100万円近く
【データ】Yahoo!知恵袋（2025-06）：Threads の「無料占い」→ Instagram → DM →「すごい先生を紹介する」
　回答者の説明する手口：無料で信用 → 「このままだと悪い方向へ」と脅す → 有料へ → 依存 → 数珠・パワーストーン
【データ】note（Ayu）：Threads の「無料占い」を試したら、
　DMで年齢と悩みを聞かれ → LINE → 外部サイトのURL。そのサイトは「危ない占いサイト」の一覧に載っていた。
　「無料占い」は、実は外部の占いサイトへの紹介料（アフィリエイト）稼ぎの入口になっている、と分析

　→ 「Threads で無料占い → LINE」という流れそのものが、
　　 一部の利用者には「詐欺の入口」として知られ始めている
　→ 九尾は、この型とは違うと一目で分かる必要がある
　　（外部サイトに飛ばさない／脅さない／値段が最初から見えている、など）

Ｈ-4　うまい人はどうしているか ―― 実例
------------------------------------------------------------------------
【データ（Threads 上の実際の返信）】占いアカウント「こよみ」
　コメントへの返信の中で：
　「コメントをいただきありがとうございます💌
　　①こよみをフォロー
　　②公式LINEリンクから『無料鑑定』と送ってください
　　お二人の心が再び寄り添うためのヒントを、霊視でお伝えします🌸 lin.ee/…」
　→ 返信の中に LINE のリンクを直接貼る型。フォローもお願いしている

【データ（Threads 上の実例）】
　「フォロー後プロフィールの公式LINEアイコンをタップ→プロフィール文の下から『無料占い』とお送りください」
　「無料鑑定を希望する方はフォロー下の公式ラインアカウントに登録して LINE から申し込んでください」
　→ リンクを貼らず「プロフィールから」と案内する型

【定説】プロフィールで「この人をフォローする価値があるか」を数秒で判断される。
　誰に何を届けるか／信用できる実績／次にどうすればいいか（リンク・固定投稿）が要る

【データ】無料占いのとき聞くのは3つが多い：名前（呼び名）、生年月日、悩みの種類（恋愛・復縁・仕事 等）

Ｈ-5　数字（事業の売却サイトに出ている実データ。ここが一番具体的）
------------------------------------------------------------------------
　※ラッコM&A の掲載。売り手の申告なので【データ】だが、盛られている可能性はある

【例1】AI占い・Threads 2アカウント＋公式LINE（掲載 2026-05-26、運営開始 2025-12）
　　フォロワー 計1,800人（1,200＋600）
　　直近90日の閲覧 計40万回（29万＋11万）
　　LINE 登録 約2,691人 ← フォロワーより多い
　　投稿 198件
　　売上 月42万円前後（最高60万円）、利益 月40万円前後
　　流れ：Threads → 公式LINE → 個別鑑定を販売。投稿と鑑定文はAIで作成。1人で運営
　→ 読み取れること：
　　・フォロワーが少なくても LINE 登録は取れる。
　　　「フォローされる」と「LINE に来る」は別のこと。投稿を見た人が直接 LINE に来ている
　　・閲覧40万/90日に対して LINE 2,691人（5か月の累計なので単純比較はできないが、
　　　閲覧の0.5%前後が LINE に来ている計算になる）
　　・LINE 1人あたり月の売上は 160円前後（42万÷2,691）

【例2】AI占い・Instagram＋Threads 5アカウント（掲載 2026-01-28）
　　フォロワー 計約10万人 → LINE 有効1.5万人 → 購入者600人（LINE の4%）
　　売上 月210万円、利益 月191万円
　　「AIによる自動返答機能搭載（まれに手動対応が必要）」← LINE 内の自動応答のことと思われる
　　固定費：LINE公式 月5万円、Lステップ系ツール 月5万円、問い合わせ外注 5万円、投稿外注 4万円

【例3】占い×AIアート・Threads（掲載 2026-01-06、運営開始 2025-05）
　　フォロワー 7.3万人、最大で月1,000万閲覧、直近30日 103万閲覧
　　LINE 登録 わずか544人（フォロワーの0.75%）
　　売上 月数千円〜数万円、女性が約97%
　→ 読み取れること：
　　・見た目（画像）でバズっても、LINE に来る理由がないと来ない
　　・表示やフォロワーの数と、LINE 登録・売上は比例しない

【例4】note（林知佳さん、タロット占い師）
　　フォロワー約300人の休眠 Threads で「無料でタロット占いします」
　　→ 1日で30人を占い、うち3人が有料相談（計3,000円）、Threads フォロワー＋17
　　（返事は Instagram の DM に誘導）
　→ 読み取れること：少ないフォロワーでも「無料で占う」は反応が来る

【データ（ツール会社の宣伝が多い。割り引いて読む）】

■ そこからの案（Claude の考え）
========================================================================

　・LINE へのつなぎ方は大きく3つ。どれにするかは要相談
　　Ａ．返信の中に LINE のリンクを貼る（こよみ型）
　　　　＋ その場で動ける。− 全返信に貼ると「繰り返し」に見える。売り込みに見える
　　Ｂ．返信では「プロフィールから」と言葉で案内（リンクなし）
　　　　＋ スパムに見えにくい。− 一手間増えるぶん減る
　　Ｃ．返信では一切誘わない。プロフィール・固定投稿・投稿本文に任せる
　　　　＋ 会話が純粋になり、表示が伸びやすい（はず）。− 動く人は減る
　　→ 全員に同じにする必要はない。
　　　「相手が自分の悩みを書いてきた」「もっと知りたいと言った」時だけＡかＢ、それ以外はＣ、
　　　のように相手によって変える作りが考えられる

　・「コメントしてくれたら無料で占います」型の投稿は、日本では普通だが、
　　Meta の基準ではコメントねだりに当たりうる。
　　投稿は山崎さんの担当だが、自動返信はその投稿の「受け」なので、どの型の投稿に付けるかで作りが変わる

　・九尾は「詐欺の型」と違うことを、返信の中でも示せる
　　（外部サイトに飛ばさない、LINE の中で完結、料金が明示、脅さない）
　　逆に、返信で「今のままだと…」のような不安をあおる言い方は、
　　LINE 規約の「霊感商法等」・消費者契約法（→ 10）の両方に触れうる。返信の禁止表現に入れるべき

　・数字の手本は例1。フォロワー1,800人でも LINE 2,691人。
　　「フォロワーを増やす」より「見た人が LINE に来る理由を作る」方が効く可能性がある

　・今の仕様書の「重い相談には『DMか公式LINEで』と返す」は、
　　Threads の DM は自動では読めないので、DM に来ても誰も返せない。直す必要あり
