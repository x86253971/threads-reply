■ まず読むべき10個
========================================================================

　１．返信は本当に効く ……【公式発言】【データ】【確定】の3方向から裏付けあり
　　　モセリ氏「返信すべての価値の合計は、投稿すべての合計とだいたい同じ」(2024-07)
　　　Buffer の調査で、投稿者が返信すると反応 +42%（6つのSNSで最大）(2026-02)　→ 02

　２．効くのは「返信の数」より「会話の続き」
　　　Meta が公開している並べ方の説明に「返信の、さらに下で起きた反応（過去1時間・6時間）」が
　　　何度も出てくる。往復が続く投稿ほど評価されると読める　→ 01・02

　３．ただし「すべての返信が良いわけではない」
　　　モセリ氏が明言。反応ねだり（コメントして／いいねして）は Meta が下げる対象と公式に定めている。
　　　「コメントくれたら無料で占います」はこれに当たりうる　→ 03

　４．★ Threads には DM を送る API が無い
　　　Instagram で流行っている「コメントした人に自動でDM」は作れない。
　　　自動でできるのは公開の返信だけ　→ 04

　５．フォロー外には届きにくくなっている
　　　2024-11 モセリ氏「フォロー外への表示は減り、フォロワーへの表示が増える」。
　　　Threads 全体の反応率も 4.4%→3.6% に下がった　→ 01・11

　６．★「Threads の無料占い → LINE」は、詐欺の入口として警戒され始めている
　　　知恵袋・note で注意喚起。国民生活センターに占いサイトの相談が毎年約1,000件。
　　　九尾は「外部サイトに飛ばさない・料金が見える・脅さない」で違いを示せる　→ 05・06

　７．フォロワーが少なくても LINE は取れる
　　　実際に売られた事業：Threads フォロワー1,800人で LINE 2,691人、月売上42万円。
　　　逆に、フォロワー7.3万人でも LINE 544人・売上数千円の例もある　→ 05

　８．LINE へのつなぎ方は3通り（リンクを貼る／言葉で案内／誘わない）
　　　日本の占いアカウントは「コメントへの返信にLINEリンク」をふつうにやっている。
　　　Meta・LINE とも、外へ誘うこと自体を禁じる決まりは見つからなかった。
　　　ただし同じ文の繰り返しはスパム扱いの対象　→ 05

　９．言ってはいけないことが法律で決まっている
　　　「このままだと不幸になる」型は、消費者契約法（霊感商法・10年取り消し可）と LINE 規約の両方に触れうる。
　　　「必ず当たる」は景品表示法　→ 10

　10．攻略記事の数字の多くは出典がない
　　　「最初の30分」「100反応」「8語以上」「返信はいいねの10倍」などは根拠が見つからない。
　　　分からないところは、九尾で試して測るしかない　→ 09・11

■ 今の試作（返信システムの仕様書・コード）とぶつかる点
========================================================================

　調査の前に作った試作なので、直す前提。見つかった点だけ並べる。

　・重い相談への返し文「よければDMか公式LINEで」
　　→ DM は自動では読めない。弱っている人を商品の LINE に誘う形にもなる（→ 08）
　・決まった3文（fallback）の使い回し
　　→ スパムの「繰り返し」に近い。中身のない返信は評価も上がらない（→ 02・04）
　・トークンの延長
　　→ 延長の返事に新しいトークンが入って返ってくるが、今は保存していない。
　　　文字列が変わる場合、60日で止まる可能性（実物で確認が要る）（→ 04）
　・「記録を一切持たない」作り
　　→ 二重返信は防げるが、効いたかを測れない。測るための記録は別に要る（→ 09）
　・返信の禁止語
　　→ 不安をあおる言い方（このままだと・不幸・手遅れ 等）が入っていない（→ 10）
