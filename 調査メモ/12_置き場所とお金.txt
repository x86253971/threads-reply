１．GitHub Actions（いまコードを置いた場所）
------------------------------------------------------------------------
【確定】公開リポジトリなら無料・上限なし。非公開は月2,000分まで
　出典: docs.github.com/en/billing/concepts/product-billing/github-actions
【確定】自動で動かす間隔は最短5分。混むと遅れる（数分〜十数分）
【確定】★ GitHub の規約で、Actions を次の用途に使わないよう書かれている
　「サーバーレスアプリの一部として使う」
　「リポジトリのソフトを作る・試す・配る・公開する、と関係ない活動」（GitHub のサーバーで動かす場合）
　出典: docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features
　→ 返信ボットを常に動かし続ける場所として使うのは、この規約に引っかかりうる（グレー）
　→ 1回のジョブの中で何時間もループさせて1分おきにする方法は、なおさら良くない
　※ 九尾の投稿の保管庫（毎朝4時に1回）も GitHub Actions で動いている。1日1回で負担は小さいが、同じ種類の話

３．Cloudflare Workers（1分おきの候補）
------------------------------------------------------------------------
【確定】出典: developers.cloudflare.com/workers/platform/limits/ ・ /workers/configuration/cron-triggers/
　・1分おき（* * * * *）で動かせる。無料プランでも使える。1つのアカウントで5本まで
　・無料プランの1回あたりの制限
　　　CPU を使える時間 10ミリ秒（通信を待っている時間は入らない）
　　　外への通信 50回まで（Threads・Gemini・保存先への通信をぜんぶ合わせて）
　　　1日のリクエスト 10万回まで
　・有料プラン（月5ドル）にすると、この制限はほぼ気にしなくてよくなる
【確定】記録の置き場 KV（無料）：読む 1日10万回／書く 1日1,000回／容量 1GB
　KV の読み書きは「1回あたり1,000回まで」で、上の通信50回とは別枠
　出典: developers.cloudflare.com/kv/platform/limits/
【確定】D1（データベース）は、1回あたり50回までで、通信50回と同じ枠を使う → KV の方が向いている
【定説・要確認】Cloudflare から Gemini を呼ぶと、動いた場所によっては
　「この地域では使えません」と断られることがある、という開発者の報告がある

５．1分おきにしたときの数（Claude の計算）
------------------------------------------------------------------------
　・1日 1,440回の見回り
　・Threads への問い合わせ：1回で「自分」「投稿一覧」「投稿ごとの会話」→ 投稿10本なら12回
　　→ 1日 約1.7万回。Threads の上限（表示が少なくても1日4.8万回）に収まる
　・AI（Gemini）は新しいコメントがあったときだけ呼ぶので、1分おきにしても回数は増えない
　・ただし Cloudflare 無料の「通信50回」に入れるには工夫が要る
　　　投稿10本を毎分見ると、それだけで12回。コメント1件の処理に5回前後
　　　（仕分け1・作文1〜2・返信を送る2）→ 1回で返せるのは5〜7件くらい


========================================================================
■ そこからの案（Claude の考え）
========================================================================

　おすすめ：Cloudflare Workers（無料）＋ KV に記録
　　・お金：0円で始められる。足りなければ月5ドルで制限がほぼ外れる
　　・1分おきにできる。パソコンを閉じていても動く
　　・GitHub の規約のグレーからも外れる（GitHub はコードを置くだけにする）
　　・記録の置き場も同じ所（KV）で済み、九尾の LINE の Redis の枠を食わない

　無料の制限に合わせる工夫
　　・毎分見るのは、最近の投稿（例：2日以内）だけ。古い投稿は10分おき
　　・1回で返すのは数件まで。残りは次の分に回す（1分おきなので遅れは小さい）
　　・投稿の画像を AI に見せるのは、CPU の10ミリ秒を超えるおそれがあるので、最初は止める

　残る心配（作る前に小さく試して確かめる）
　　・CPU 10ミリ秒に本当に収まるか
　　・Gemini が「地域で使えない」と断られないか
　　・→ どちらかでつまずいたら、月5ドルの有料プランにするか、別の置き場所を考える

　別の案
　　・パソコンで1分おき（無料）：閉じている間は止まる。前に2週間止まって気づかなかった反省がある
　　・GitHub で10分おき（無料）：規約のグレー。速さも遅れも、1分おきには遠い

　山崎さんに決めてほしいこと
　　Ｑ７．Cloudflare（無料、だめなら月5ドル）で進めてよいか
　　　　　Cloudflare のアカウント作成は山崎さんの操作が要る（メールアドレスで作れる。カードは無料なら不要）
　　Ｑ８．九尾の LINE の Vercel が無料プランかどうか、確かめてほしい
　　　　　（Vercel の画面の Settings → Billing で分かる）。無料なら本番の前に対応が要る
