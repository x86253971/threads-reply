設計案：Claude が作るなら、こんな自動返信にする

調査メモ（調査メモ\00〜11）をもとにしています。→ のあとの番号は根拠のファイル。

■ 1．ひとことで言うと
========================================================================

　「全部に速く返すボット」ではなく、
　「コメントを読み分けて、往復が続くように返す九尾」を作る。

　前の試作との違い
　　前：来たコメントに AI で一言返す。失敗したら決まった3文のどれかを返す。記録は持たない。
　　案：コメントを種類で分ける → 種類ごとに返し方を変える → 送る前に点検する
　　　　→ 送ったものを記録する → 週に1回「効いたか」をまとめる。

　理由
　　・Meta は「返信の数」より「会話の続き」を見ている（→ 01・02）
　　・量で押す・同じ文を繰り返すのは、スパム扱いの方向（→ 03・04）
　　・前の9垢は「動いていたが伸びなかった」。効いたかを測れなかった（→ 09・11）

■ 2．全体の流れ（10分おきに1回、これを回す）
========================================================================

　①　見回る
　　　九尾の最近の投稿（例：直近7日ぶん）に来たコメントを集める。
　　　九尾の返信にさらに返してきたもの（往復の続き）も集める。

　②　もう返したものを外す
　　　今の「二重返信防止」の仕組みはそのまま使う。

　③　仕分ける（AI 1回目）……3章
　　　コメントを7種類のどれかに分ける。

　④　返すかどうか決める（決まりで判断。AI は使わない）……4章
　　　種類・時間帯・その人への返信回数・1日の上限で決める。

　⑤　文を書く（AI 2回目）……5章
　　　種類ごとに違う指示で書かせる。

　⑥　点検する（決まりで判断＋必要なら AI 3回目）……6章
　　　禁止表現・繰り返し・長さ・生年月日などを見る。だめなら書き直し、それでもだめなら「送らない」。

　⑦　送る
　　　1件ごとに少し間をあける（間の長さは毎回少し変える）。

　⑧　記録する……8章
　　　何を・いつ・どの型で返したか。あとで相手が返してきたかを見る。

　⑨　まずいことが起きたら山崎さんに知らせる
　　　重い相談が来た・エラーが続いた・トークンが切れそう、など。九尾の LINE で山崎さんに通知。

■ 3．仕分け：コメントを7種類に分ける
========================================================================

　　種類　　　　　　　例　　　　　　　　　　　　　　　　　返し方
　──────────────────────────────────────────────────────
　Ａ 感想　　　　　「当たってる！」「刺さった」　　　　　短く受け止めて、相手の言葉を拾う。ときどき質問で返す
　Ｂ 質問・軽い相談「私の場合はどうですか？」　　　　　少しだけ中身を見せる。続きは LINE も選べる（7章）
　Ｃ 占ってほしい　「占ってください！」「〇年生まれです」コメント欄では占わない。LINE を案内（7章）
　　　　　　　　　　　　　　　　　　　　　　　　　　　　　生年月日を書いてきた人にも、それには触れない
　Ｄ 重い相談　　　「死にたい」「もう無理」　　　　　　　別扱い（9章）★
　Ｅ 荒らし・宣伝　悪口、宣伝リンク、勧誘　　　　　　　返さない（隠す機能を使うかは★）
　Ｆ 返事が要らない絵文字だけ、スタンプ的なもの　　　　返さない、またはごく短く
　Ｇ 往復の続き　　九尾の返信にさらに返してきた　　　　会話を続ける。ただし上限あり（4章）

　・仕分けは AI に「種類と、その理由を一言」で答えさせる。
　・自信がないときは安全な方に倒す（Ｄっぽいなら Ｄ、Ｅっぽいなら返さない）。
　・「死にたい」などの言葉は、AI の判断の前に言葉のリストでも拾う（二重の網）。

■ 4．返すかどうかの決まり（AI ではなく、決まった数字で判断）
========================================================================

　・夜中（1〜7時）は送らない。たまったものは朝に回す（今の試作と同じ）
　・同じ人・同じ投稿への返信は 3回まで（今の試作と同じ）。往復はそこで自然に締める
　・1回の見回りで送るのは最大 12件（今の試作と同じ）。1日の合計にも上限を置く（例：100件）
　　→ API の上限（1,000件/日）よりずっと手前。問題は上限ではなく「機械っぽく見えるか」（→ 04）
　・返信の量は急に増やさない。始めは少なく、様子を見て増やす
　・他人の投稿には返さない（自分の投稿のコメント欄だけ）（→ 04・11）
　・コメントが来てから送るまでの時間は★（すぐ／少し待つ）。測って決める（→ 09 の２）

　数字はすべて config（設定ファイル）に書き、山崎さんが変えられるようにする。

■ 5．文を書く：九尾らしく、相手の言葉を拾って
========================================================================

　AI に渡すもの
　　・九尾の人物像と話し方（今の config の persona を土台に、もっと具体的に）
　　・元の投稿の本文（何の話へのコメントか）
　　・コメント本文（往復の続きなら、それまでのやりとり全部）
　　・種類（Ａ〜Ｇ）と、その種類での返し方
　　・良い返信の見本を数個（★山崎さんが選ぶ／書く。九尾の声の基準になる）
　　・やってはいけないことの一覧（6章）

　書き方の決まり
　　・相手の言葉を1つは拾う。「ありがとうございます！」だけの中身のない返信はしない（→ 02）
　　・質問で終える返信を混ぜる。ただし毎回ではない（毎回だと尋問っぽく、反応ねだりにも見える）
　　・長さは 15〜90字くらい（今の試作と同じ。測って調整）
　　・占いの「当てる」言い方・断定はしない。「〜かもしれません」「〜の流れが見えます」程度
　　・九尾のキャラは崩さない。ただし人を見下す・からかう方向にはいかない

　※ 投稿文は山崎さんが書くもの。この仕組みが書くのは「コメントへの返信」だけ。

■ 6．送る前の点検（ここがいちばん大事な安全網）
========================================================================

　決まりで見るもの（AI を使わず、機械的に）
　　・禁止表現：不安をあおる（このままだと・不幸・手遅れ・祟り・呪い 等）、
　　　断定（必ず・絶対当たる・100%）、健康とお金の断定（治る・儲かる 等）（→ 10）
　　・生年月日・本名・住所・電話番号を書かせる文になっていないか（→ 05）
　　・URL：決めた LINE の URL 以外は入れさせない
　　・長さ：短すぎ・長すぎ
　　・繰り返し：最近送った返信（例：直近200件）と似すぎていないか
　　　→ 似すぎていたら書き直し（→ 04 スパムの「繰り返し」）

　AI で見るもの（必要なら）
　　・相手のコメントにちゃんと答えているか、失礼でないか

　だめだったら
　　・1回だけ書き直させる。それでもだめなら「送らない」
　　・★ 前の試作の「決まった3文を代わりに送る」はやめる案。
　　　　返さないより、中身のない同じ文を返す方が害が大きいと考えるため（→ 02・04）

■ 7．LINE への案内（★Q1 で決める。ここは仮の案）
========================================================================

　仮の案：「相手によって変える」
　　・案内するのは、Ｂ（悩みを書いた）・Ｃ（占ってほしい）・Ｇで「もっと知りたい」と言った人だけ
　　・Ａ（感想）には案内しない
　　・同じ人に案内するのは1回まで（しつこく見せない）
　　・案内の文は毎回少し変える。九尾の言葉で、押し売りにしない
　　・Ｄ（重い相談）には絶対に案内しない（9章）

　案内のしかた（どちらにするか★）
　　Ａ案　返信に LINE のリンクを貼る　→ clicks で数えられる（→ 04・09）
　　Ｂ案　「プロフィールの LINE から」と言葉で案内する　→ リンクが無いぶん、警戒されにくい？

　「詐欺っぽく見えない」ための決まり（→ 05・06）
　　・外部の占いサイトには飛ばさない（LINE だけ）
　　・「無料で全部わかる」と言わない。無料でできること・有料のことを正直に
　　・急がせない（「今だけ」「先着」などを返信で言わない）

■ 10．始め方：いきなり本番にしない（3段階）
========================================================================

　段階１　下書きだけ（送らない）
　　・本物のコメントを読んで、仕分け・返信文・点検まで全部やるが、送らない
　　・「こう返すつもりでした」の一覧を山崎さんに見てもらう（メモ帳で読める形）
　　・ここで九尾の声・禁止表現・仕分けの精度を直す
　　・AI を2つ並べて（例：Gemini と Claude）同じコメントに書かせ、比べることもできる

　段階２　一部だけ送る
　　・種類Ａ（感想）だけ、など安全なものから送り始める
　　・1日の上限を低くして様子を見る

　段階３　ふつうに動かす
　　・週1のまとめを見ながら、数字（上限・長さ・待ち時間・LINE 案内の仕方）を調整

　　・いま九尾についているコメントは、ほとんどが「🦊」だけ（13件中12件）
　　　投稿の側で「コメント欄に🦊を置いていって」「🦊を置いてくれた方へ、今の縁の廻りを伝えます」と
　　　呼びかけているため

　　・とくに 10/7 朝6時の投稿は「🦊をくれた人に伝えます」と約束している。返さないと約束を破る形になる
　　・一方で、設計案は「コメント欄では占わない」（C）。🦊に一人ずつ短く占いを返すなら、ここを変えることになる
　　　→ これは 99 の Q4（投稿の型との組み合わせ）そのもの。山崎さんに決めてもらう

　　考えられる形
　　　Ｈ案　「合言葉への返事」という種類を足す。投稿が呼びかけた合言葉（🦊 など）には、

　　　Ｉ案　合言葉には、受け止めの一言だけ返す（占いの中身は書かない）
